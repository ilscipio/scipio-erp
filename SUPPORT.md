# Support

## Issues

Open an issue only for a bug. Each bug report must contain these items:

- The Scipio version and the Java version.
- The steps that reproduce the bug.
- The expected result and the actual result.
- The relevant part of `runtime/logs/error*.log`.

We close an issue without a reproduction. We close questions and feature requests.

## Help

We do not give free support. We do not promise an answer time for an issue.

For help with installation, setup, development or operation, use a paid plan.
See [https://www.scipioerp.com](https://www.scipioerp.com).

## Security

Do not open an issue for a security problem. Use [https://www.scipioerp.com/security/](https://www.scipioerp.com/security/).
